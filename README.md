# Onshape → SCM Maestro (.pgmx)

FeatureScript für Onshape, das aus Plattenteilen automatisch CNC-Programme für SCM Maestro erzeugt
(2,5D: Umfräsen, Falz, Bohren, Taschen) – möglichst mit Original-SCM-Makros.

| Ordner | Inhalt |
|---|---|
| `maestro/beispiele/` | Beispiel-Programme (.pgmx) aus Maestro |
| `maestro/makros/` | SCM-Makros |
| `maestro/werkzeuge/` | Werkzeugdaten (.tlgx o. ä.) |
| `featurescript/` | Das Onshape-FeatureScript |
